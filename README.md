# Signage (Fire Stick digital signboard)

Files
- index.html: the dashboard (layout editor, screens, pairing). Sign-in required.
- player.html: open this on each Fire Stick. Shows a pairing code, then the assigned layout.
- render.js: shared drawing code. config.js: your Supabase URL and publishable key. supabase.js: Supabase library (v2.119.0).
- schema.sql: run once in Supabase → SQL Editor.

All files must be hosted together in one folder (GitHub Pages, Netlify or Vercel).
